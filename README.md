# Ogre Chambers 2222 - Buffed Weapons Mod

A lightweight balance mod for Ogre Chambers 2222.

## Features
* +25% Bullet Damage
* +20% Projectile Speed
* +25% Bullet Range / Lifetime
* +15% Fire Rate Boost:
## Requirements
* Windows x64
* Antenni Loader v1.0.0 (or later)
* .NET 10 Desktop Runtime x64 installed on your PC.

## Installation Instructions
1. Go to the **Releases** section and download `BuffedWeaponsModv1.zip`.
2. Locate your Ogre Chambers 2222 installation folder (Right-click game on Steam -> Manage -> Browse local files).
3. Extract the zip and put the extracted folder in the following path: `.../Ogre Chambers 2222/antenni/mods/`
4. Verify that the files are placed correctly at this exact path:  `.../Ogre Chambers 2222/antenni/mods/`
5. Make sure inside the folder are the following `BuffedWeaponsMod.dll` and `modinfo.json`.
6. Launch the game normally through Steam and it should work!
